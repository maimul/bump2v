into a versioning tool that works for any language, CI pipeline and AI coding agent. Each file is
the track's report as returned, with local paths made repo-relative. Every factual claim carries a
source link; download and star counts are snapshots from that day. Items marked "inference" are the
researcher's reading, not sourced fact. Check a claim against its source before quoting it.
